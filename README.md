# UserTitleGenerator

> A lightweight, web-based tool for creating custom user title images and badges.

[![GitHub Pages](https://img.shields.io/badge/site-live_demo-brightgreen?style=flat-square)](https://absentservices.github.io/UserTitleGenerator)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg?style=flat-square)](LICENSE)

A simple, pure HTML/JS utility designed to generate clean user titles and forum-style badges on the fly. Free and open for any personal or commercial use—do as you wish with it!

## ✨ Features

- **Lightweight & Fast:** Built with standard HTML, CSS, and JavaScript—no dependencies or heavy frameworks.
- **Zero Configuration:** Runs directly in any web browser.
- **Fully Customizable:** Easily adapt the styling, canvas logic, or markup to fit your forum, community, or web application.
